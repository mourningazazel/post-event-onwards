# PEO-073 · Auto-config: calibrate horde and active-area costs per machine, set both continuously, adapt the window live (D-034)

## Goal

At first launch or on request, a short calibration fits the machine's update cost per Dead, per active cell and per stage cell, then sets horde size and active window as real numbers inside the budget, weighted by a player preference; a slow controller adjusts only the active window from measured update times; settings are recorded with the seed. Since PEO-117 the screen shows a view sized by the window. The active window (scent work, D-034) is separate; whether it may be smaller than what the screen shows is a question for this brief.
