# PEO-119 · Sight: 500 ft optical range in core (D-049)

## Goal

Core knows what the player can see: an optical range of about 500 ft (152 tiles at 1 m, ADR-0013) round the player, with a hook for binoculars to extend it later; the view draws only what is seen, which matters once zoom (D-050) can show more than the range. Whether walls block sight (line of sight) is settled at brief time.
