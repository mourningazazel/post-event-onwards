# PEO-118 · One continuous map: no stage jumps (ADR-0007, D-041)

## Goal

The world is one continuous map the player walks with no barrier or jump between places, proven at real size (ADR-0007, D-041, D-059). Split into PEO-144 to PEO-151; this item is the umbrella and closes after PEO-151, with an Architect check of the whole.

## Context

- Order: PEO-144 real-size dev game; PEO-145 real-size test harness (waits on D-060); PEO-146 terrain by world cell and chunk; PEO-147 World as a window over the map, no exit; PEO-148 memory and items by world cell; PEO-149 the window follows the player, the Dead per chunk; PEO-150 save; PEO-151 names and docs
- Technical method (Architect, 2026-10-14): 32-cell chunks and 64-bit world cells; a resident dense window (the D-034 active area, 1024 by default) that moves by whole chunks, so the field kernels keep their dense grids; per-chunk records for the Dead that leave, closed-form catch-up on return (ADR-0019); memory and items keyed by world cell; scent dropped outside the window

## Units

## Acceptance

- In game, a player walks 2 km in any direction from the start with no edge, exit or jump, at the default 1024 square window with play density
- Walking back finds terrain, remembered cells, ground things and the Dead (thinned) as left
- Save, restore and walk on: bit-identical to the world never saved
- The real-size cases (PEO-145) pass in CI
