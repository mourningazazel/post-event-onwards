# PEO-040 · World clock: one-second ticks; actions carry durations (D-015)

## Goal

Per D-015. The world counts game seconds; scent and the Dead update on a fixed cadence (default 6 s, a named tunable) independent of player actions. Each Action carries a duration in seconds (walk 6) and lands between updates; the player's scent is logged per second on the occupied tile and applied at the next update. Rates move to per second; Dead speeds become seconds per step. Speculation computes the next update while idle and patches only around tiles the player touched since the last one; the golden test stays bit-exact. Walking behaviour at the default cadence should match today's.
