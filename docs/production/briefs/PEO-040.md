# PEO-040 · World clock: one-second ticks; actions carry durations (D-015)

## Goal

Per D-015. World steps in one-second ticks; each Action has a duration in seconds (walk 6); step advances that many ticks. Rates move from per step to per second: live scent retuned to spread as far per game second as today, Dead speeds become seconds per step. Speculation computes ticks ahead while idle; after an N-tick action only the cone within about N cells of the player is redone, generalising PEO-007's repatch radius; the golden test stays bit-exact. Measure walking-step cost (6 ticks) at 200x120, 5,000 Dead before optimising.
