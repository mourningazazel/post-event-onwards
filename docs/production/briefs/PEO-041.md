# PEO-041 · Running: a step that takes 3 seconds (D-015)

## Goal

Per D-015. The player can toggle running. While running, a step takes 3 game seconds instead of 6, so the player covers two cells per 6 s update while the Dead keep their pace. The map looks the same; only a HUD word shows the mode. Scent follows time, not steps: a running step logs 3 s on its tile, so a runner deposits half a walking step's scent per cell and the same total per second (PEO-040's occupancy log already does this).

## Context

- docs/production/decisions.md (D-015, D-011)
- src/core/include/peo/core/action.hpp (kStepSeconds, Action::step(dir, seconds))
- src/app/main.cpp (action_for, SDL_AppEvent, draw's HUD line)
- tests/core/test_world.cpp ('two 3 s steps share one update's scent')

## Units

- core: in action.hpp add `inline constexpr Seconds kRunStepSeconds = 3;` beside kStepSeconds, with a one-line comment naming D-015. No other core change: World already takes any duration.
- app: in src/app/main.cpp add `bool running = false;` to App. R toggles it (not a turn: no action, no speculation change, not subject to the D-011 cap) and marks the screen dirty. action_for takes the mode and builds steps with kRunStepSeconds when running, kStepSeconds otherwise; waits stay kWaitSeconds in both modes. The mode persists across stages (N and reaching the exit do not reset it).
- app: the HUD line shows `walk` or `run` after the turn count and adds `[r]` to the key hints. Nothing else on screen changes.
- test: tests/core/test_world.cpp gains 'a runner moves two cells per update': from a clear start, two run steps in one direction move the player two cells and updates() rises by exactly 1; four run steps give 4 cells and 2 updates; the summed deposit over those updates equals that of walking the same 12 s (compare total scent mass before clamp, or the occupancy log's seconds, which must sum to 12).
- docs: one line in docs/architecture.md, beside the D-011 cap line, saying R toggles running (3 s steps, D-015) and that the cap limits key presses, not game time.

## Acceptance

- holding a direction while running covers two cells for every update the Dead take, and the Dead move no faster than when walking
- a runner's scent per game second equals a walker's; per cell it is half (the new test passes)
- R changes only the HUD word until a step is taken; toggling never spends a turn
- commit(speculate()) stays bit-identical (the existing mixed 3/6/12 s golden test passes unchanged)
- the suite stays under 1 s

## Manual

- peo 7: walk 10 steps toward some Dead and count how many cells they close; reload, press R, run 10 steps the same way. The Dead should close about half as many cells relative to your distance covered, and the HUD reads run.
- Press R several times without moving: the turn counter does not change and spec:hit stays.
- Run into the exit, then press N: the HUD still reads run.

## Out of scope

- stamina, fatigue or noise from running
- any visual change to the player or map beyond the HUD word
- bicycles and other multi-cell movement
- changing the D-011 key cap
