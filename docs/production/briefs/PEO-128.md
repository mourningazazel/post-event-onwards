# PEO-128 · Content derivations in core: capabilities, mass estimate, packing, soak and search, integer spec first

## Goal

Core computes every derive.py derivation (capabilities, total_mass, mass_estimate, throw range, impact outcome, packed_dims, search_seconds, soak) in integer maths from the PEO-008 registry, matching derive.py exactly on the whole content tree. derive.py uses floats and log2/sqrt today, so its integer form is settled in Python first, the content expectations re-pass, then the port is golden-checked like PEO-008.
