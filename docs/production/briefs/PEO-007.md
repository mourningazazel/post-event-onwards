# PEO-007 · Compute the next turn while waiting for input

## Goal

Between turns the world speculates the next turn assuming Wait; on input, commit() patches only the player's neighbourhood and produces state bit-identical to step().

## Context

- docs/architecture.md#computing-while-waiting
- docs/production/decisions.md
- src/core/include/peo/core/world.hpp
- src/core/include/peo/core/scent.hpp
- src/core/include/peo/core/dead.hpp

## Units

- core: make ScentField::step linear-then-clamp explicitly: split into step_linear(blocked) and clamp_floor(); step() calls both. Add ScentField::patch_deposit(Vec2i at, float amount): applies diffuse(δ) for a single deposit to the 5 affected cells (respecting walls exactly as step_linear does), assuming the field is already post-step_linear. Test: for random fields and deposits, step_linear on (field+δ) equals step_linear(field) then patch_deposit(δ), exactly (use == not Approx; choose operation order so this holds).
- core: add struct Speculation { ScentField scent; std::vector<Dead> horde; Tick turn; } and World::speculate() const -> Speculation: the full turn assuming Action::wait() and no player deposit. Pure; no member mutation.
- core: add World::commit(Speculation&&, Action): apply the action, patch_deposit at the player's cell, clamp_floor, then re-run the move decision only for Dead within 2 cells of the player's new cell (reset them from the pre-turn positions kept in the Speculation), resolve contact, adopt the result. Add static bool World::equivalent(const World&, const World&) for tests.
- test: golden test in tests/core/test_world.cpp: for 200 random (seed, action sequence) pairs, run A: step(action) each turn, B: commit(speculate(), action) each turn; assert equivalent() after every turn. Include steps into walls and stage transitions.
- test: perf sanity (headless-release): at 200x120 with 5000 Dead, report microseconds for speculate() and commit() via doctest -d; commit must be under 1 ms on the Builder's machine (record the number).
- app: main.cpp spawns one std::jthread that, whenever the world is idle and no speculation exists, computes world.speculate() into a buffer; the input handler calls commit() if a fresh speculation exists, else step(). The renderer reads only the committed World. Add an on-screen HUD flag 'spec:hit/miss' for the manual test.
- docs: architecture.md 'Computing while waiting' gets the final function names and the measured numbers.

## Acceptance

- golden test passes for 200 random sequences: commit(speculate()) is bit-identical to step()
- commit() under 1 ms and speculate() under 16 ms at 200x120 with 5000 Dead on the Builder's machine (release)
- core spawns no threads; the only thread lives in src/app/main.cpp
- in game, HUD shows spec:hit on nearly every turn when playing at human speed
