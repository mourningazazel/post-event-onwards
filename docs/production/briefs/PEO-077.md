# PEO-077 · ScentWave: write down the int32 bound on the age line

## Goal

scent_wave.hpp states the int32 bound on the age line, and a compile-time check fails the build if the constants ever shrink it below the documented life of a wave

## Context

- ScentWave::age_line() is age_cost x updates as int32; kUnreached is INT32_MIN / 2. An unreached cell's sample() underflows once age_line exceeds about 2^30, and stored values overflow when age_line plus strength exceeds INT32_MAX
- At age_cost 8 that is about 2^27 updates, 25 game years at one update per 6 s; a wave lives one stage today (World::load_stage builds a new one)
- ADR-0011's global clock: if a wave ever outlives a stage, rebase the stored values by subtracting the age line, an O(cells) pass rarely needed

## Units

- core: name the bound (a constexpr kMaxWaveUpdates derived from kUnreached, the default age_cost and strength) with a comment giving the game-time it means; a static_assert that it covers at least kMinWaveLifeSeconds (one game year is ample) at kUpdatePeriodSeconds
- core: a debug assert in update() that updates_ stays under the bound for the wave's actual params

## Acceptance

- python3 tools/verify.py passes
- Raising the default age_cost to an absurd value (try 1 << 20 locally, do not commit) fails the static_assert with a message naming the bound

## Tests

- tests/core/test_scent_wave.cpp: a case that sets a wave's update count near the bound is not possible without a test hook; the static_assert is the test. Do not add a hook

## Manual

- None

## Out of scope

- Rebasing values (only if a wave ever outlives a stage; add a queue item then)
