# PEO-077 · ScentWave: write down the int32 bound on the age line

## Goal

age_line is age_cost x updates in int32: stored values overflow after 2^28 updates and sample() on an unreached cell (INT_MIN/2 less the age line) after 2^27, about 25 game years at one update per 6 s. Unreachable while a wave lives one stage; state the bound in scent_wave.hpp with a static_assert or test, and rebase values if a wave ever outlives a stage (ADR-0011 global clock).
