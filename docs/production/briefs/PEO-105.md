# PEO-105 · verify's license check splits SPDX expressions case-sensitively, so 'MIT OR GPL-2.0' is wrongly refused

## Goal

tools/validate_docs.py (PEO-093, ca7fea8) splits license expressions on lowercase or/and only; canonical SPDX uses OR/AND. Fails closed (false refusals, never false passes). Split case-insensitively and add a self-test case.
