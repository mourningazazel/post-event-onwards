# PEO-033 · Nothing enforces the 500 ms suite budget, so it is breached silently

## Goal

Exceeding the headless suite's time budget fails a check instead of going unnoticed.

## Context

- AGENTS.md (the suite runs in under 500 ms)
- tests/CMakeLists.txt
- tools/verify.py

## Units

- test: the budget in AGENTS.md is enforced by nobody. It was breached once by a 100-tick warm-up (PEO-027), fixed, and breached again immediately by PEO-002's new cases, and each time it was found by hand. Give ctest a timeout that reflects the budget, or have verify.py measure the suite and fail past it.
- test: whatever the mechanism, the failure message must name the slowest cases so the next person knows where the time went, not merely that the total is too high.

## Acceptance

- a suite that exceeds the budget fails a check rather than passing quietly
- the failure names the slowest cases and their times
- the threshold lives in one place, next to or derived from the number stated in AGENTS.md

## Out of scope

- deciding what the budget should be — that is a separate call once we can see per-case cost
- optimising any particular test
