# PEO-026 · The Dead do not converge within 3 s: scent spreads ~8 cells in 20 s, so distant Dead never move

## Goal

The Dead converge from across the map: the scent field carries a usable gradient to the map edges on a 0-500 scale, so none of the Dead is ever frozen on a flat zero field.

## Units

- core: kPlayerScent already exists at src/app/main.cpp:26 as 1.0F. Raise it to 500.0F and move it into core beside ScentParams so tests and any future depositor share one constant.
- core: retune the ScentParams defaults to diffusion 0.5, decay 0.01, floor 1e-6. Use 0.5, NOT 0.8: the checkerboard mode's amplification is 1-2D, so 0.8 gives -0.6 and a sign-alternating ripple (5 direction reversals measured in the trail behind a moving player, which can pull a gradient-climber the wrong way), while 0.5 gives exactly 0 and a strictly monotone trail. See docs/design/scent-performance.md.
- test: tests/core/test_scent.cpp — add 'the scent front carries far'. Grid 34x11, source (4,5), deposit kPlayerScent every step for 40 steps. CHECK sample({19,5}) > 1e-5F and CHECK values strictly decrease along y=5 from x=5 to x=19. These numbers are measured, not estimated: the value lands at 4.55e-04 (45x the threshold) and strict decrease actually holds to d=19. Do NOT scale this up to 80x45 with 75+ steps — measured at 200 ms per test under Debug+ASan, which would blow the suite budget on its own.
- test: tests/core/test_dead.cpp — add 'distant Dead close in'. Same 34x11 field after the same 40-step warm-up; one of the Dead at (19,5) with the default speed must close at least 10 cells over 50 calls to step_horde. Measured: it closes all 15 by call 29. Never start one of the Dead outside the scent front — strongest_neighbour returns empty on a flat zero field and the unit never moves, so the test would pin 0 forever.
- app: the scent view's bands are tuned for a 0..1 field and will render as one solid block at the new scale. Make the bands relative to the field maximum or log-spaced. Overlaps PEO-024: land the second of the two on top of the first.
- docs: one line in docs/design/scent-mobs.md recording the 0-500 deposit scale, pointing at docs/design/scent-performance.md for the measurements.

## Acceptance

- the two new tests pass, and together add under 25 ms to the headless suite (measured 21.6 ms for the pair under Debug+ASan)
- in game (peo 7): standing still, the Dead begin closing from well beyond the old ~8 cells
- ScentField::step stays linear: no value-dependent decay and no pow/exp inside step. The floor flush remains the only nonlinearity, so PEO-007's step_linear + clamp_floor split survives.
- no magic numbers: the deposit and every retuned default is a named constant or a ScentParams field
- the thousand-dead case is no slower than the 0.000261 s baseline
- this item does NOT make the Dead able to intercept a moving player — that is D-008. Scope here is reach for a stationary or slow player.
