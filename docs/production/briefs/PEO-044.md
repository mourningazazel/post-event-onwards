# PEO-044 · The Dead cut corners: strongest_neighbour allows a diagonal past two walls

## Goal

A Dead never steps diagonally between two blocked orthogonal neighbours, and never cuts a wall corner: a diagonal step is allowed only when both of the two orthogonal cells it passes are open.

## Context

- src/core/src/scent.cpp (ScentField::strongest_neighbour, the kNeighbours8 loop)
- src/core/src/dead.cpp (step_dead uses it with the blocked grid)
- tests/core/test_scent.cpp, tests/core/test_dead.cpp, tests/core/test_world.cpp ('the pre-clock world is pinned')

## Units

- core: in strongest_neighbour, when `blocked` is given and d is diagonal, skip n if blocked->at(from + Vec2i{d.x, 0}) or blocked->at(from + Vec2i{0, d.y}) (both must be open; out-of-bounds counts as blocked). Orthogonal candidates are unchanged. Keep the loop allocation-free and branch-light: compute the two orthogonal flags once per diagonal.
- test: tests/core/test_scent.cpp: a 3x3 field with the strongest cell diagonal from the centre and both orthogonal neighbours toward it blocked returns no move; with one of them open it still returns no move; with both open it returns the diagonal. tests/core/test_dead.cpp: a unit at the inside of an L-shaped wall with stronger scent around the corner does not pass through the corner.
- test: re-pin 'the pre-clock world is pinned' if its value changes, once, and say in the report note that it changed because Dead that used to cut corners no longer do.

## Acceptance

- the three strongest_neighbour cases pass; no Dead ever occupies a cell reached only through a corner
- step_horde at 200x120 with 5000 Dead stays within 10% of main (report both numbers from headless-release)
- the suite stays under 1 s
