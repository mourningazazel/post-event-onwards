# PEO-066 · Stage wall density and Dead slot chance use float; FMA contraction can break M1 vs x86 bit identity

## Goal

stage_spec (kBase + kPer * i) and plan_slots compare floats against draws; arm64 clang fuses the multiply-add, x86-64 does not, so one seed can build a different stage. Move to integer per-million chances, or add -ffp-contract=off, with a test pinning a stage hash.
