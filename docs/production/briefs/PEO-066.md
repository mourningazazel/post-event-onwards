# PEO-066 · Keep the headless suite under budget as scenario tests grow (D-033)

## Goal

Two test tiers (D-033 B): the unit tier stays under 1 s for the edit-test loop, and town, scenario and long golden-run cases run in the same CI build under their own 5 s budget, each enforced by its own CTest.

## Context

- docs/production/decisions.md D-033
- tools/suite_budget.py
- tests/CMakeLists.txt
- docs/testing.md
- AGENTS.md build-and-test rules

## Units

- test: scenario cases live in doctest suites named scenario*: the town file's suite becomes 'scenario: town'; single long cases elsewhere (over ~50 ms under the sanitizers) take '* doctest::test_suite("scenario: <file>")'
- tool: suite_budget.py takes --tier unit|scenario: unit runs -tse=scenario* against the 1 s budget, scenario runs -ts=scenario* against the 5 s budget, both read from AGENTS.md
- build: CTest registers suite_budget (unit) and scenario_budget
- docs: AGENTS.md states both budgets; testing.md explains the tiers, the 50 ms rule replaces 'skip by default', and the fast loop command

## Acceptance

- ctest --preset headless runs core, suite_budget and scenario_budget, all green
- the unit tier sums well under 1 s and the scenario tier under 5 s on this machine
- no test is skipped, disabled or weakened; every case still runs in the core test
- verify.py passes

## Tests

- the budget tests themselves; peo_core_tests -tse=scenario* and -ts=scenario* each list the expected cases

## Out of scope

- making any test faster
- the release perf cases
