# PEO-144 · Real-size dev game: 1024x1024 at play density from one core constant (D-059, PEO-118)

## Goal

The dev game opens on a 1024x1024 map with the Dead at play density (11,650), taken from one named density in core that tests and tools share, and manual and perf observations from now on are taken at that size (D-059).

## Context

- docs/production/decisions.md D-059; docs/testing.md 'Writing a test' (the D-059 line)
- src/app/main.cpp:122-147: kGameStageWidth / kGameStageHeight (200x120), kMinGameStageSide, kMaxGameStageSide, kDefaultStageDead, kDensityStageWidth / Height and game_params(): the density lives in the app today
- src/app/main.cpp: `--stage WxH` parsing (:699-725, :802-810) and the startup log (:864)
- src/core/include/peo/core/world.hpp: WorldParams (initial_dead, stage_width, stage_height)
- docs/design/performance-targets.md 'Estimated ceilings' (1024 square is the planning size); docs/bottlenecks.md B1, B2, B4 and 'Multipliers'
- Measured by the Architect on the cloud runner (headless-release, one thread, seed 42, 2026-10-14): a 1024x1024 World with 11,650 Dead builds in 109 ms; a walking step's speculate takes 60 ms (75 worst) and its commit 0.5 ms; plain step() about 60 ms. Inside D-021 (100 ms, 1 ms) with little room: B1, the desire field, is about half (PEO-089 is the lever)
- Real-size cases in ctest wait on D-060 (PEO-145); this item is the game, the shared constant and the manual baseline only

## Units

- core: `play_density_dead(int width, int height)` in world.hpp beside WorldParams, with named constants for the density (40 Dead per 80x45 cells, the dev game's since PEO-117): the count for that many cells, rounded down, computed in 64-bit, never negative. Its doc comment names D-059 and says World still clamps to the open cells
- test: tests/core/test_world.cpp, unit tier: the case under Tests
- app: kGameStageWidth and kGameStageHeight become 1024; game_params() takes the count from play_density_dead and drops kDefaultStageDead and kDensityStageWidth / Height; `--stage WxH` keeps its range and still overrides; the usage text and startup log name the default
- docs: replace the game's 200x120 default where docs state it as the default (grep '200x120' and '200×120' in docs/architecture.md, docs/wiki/frontend.md, docs/wiki/tunables.md, docs/wiki/architecture.md); leave vision.md, performance-targets.md and D-021's measured sizes alone (they are perf cases, not the default)
- docs: docs/testing.md 'Manual in-game' row: manual steps run on the default 1024x1024 map unless a brief says otherwise; bottlenecks.md 'Multipliers' gets one line with the M1's speculate and commit at the new default, from the manual step
