# PEO-029 · Scent flows into walls and the map edge and is lost there

## Goal

A wall or the map edge absorbs scent exactly as an open cell would receive it, and passes none on, so scent never piles up against geometry.

## Context

- docs/production/decisions.md (Scent drifts into walls and dies there)
- src/core/src/scent.cpp
- tests/core/test_scent.cpp
- docs/design/scent-performance.md

## Units

- core: in ScentField::step, make the outflow unconditional — every open cell loses here*diffusion spread over its four orthogonal directions whether or not each neighbour is a wall or off-map. Keep the inflow gated on the mask so walls and off-map cells contribute nothing. Blocked cells are still zeroed in the back buffer, so whatever enters a wall is discarded. This removes a branch from the inner loop rather than adding one.
- test: rewrite 'walls block scent'. It currently asserts total() == 1.0, which encodes the old reflecting behaviour. Assert the new contract instead: the wall cell itself stays exactly zero, the open neighbour receives its share, and total() has decreased by the absorbed amount.
- test: 'mass is conserved without decay' now holds only while the front has not reached the edge. Either shrink the step count so the front stays interior, or rename it to state the interior-only contract and assert that. Do not delete or skip it.
- docs: one line in docs/design/scent-mobs.md noting that walls and the map edge absorb.

## Acceptance

- a wall cell never holds scent, and an open cell beside a wall is no higher than the same cell would be with the wall absent — no pile-up
- total() strictly decreases once the front reaches a wall or the map edge
- the inner loop of step() has one fewer branch per neighbour than before
- every existing test either passes unchanged or states the new contract explicitly; none is deleted, skipped or weakened
