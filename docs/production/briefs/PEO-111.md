# PEO-111 · River courses on the geography square (ADR-0018 point 4, ADR-0010)

## Goal

Each geography square carries river courses with a size class: traced downhill on the shared elevation from hashed sources, ending at the sea, a lake, another river (tributary) or a new pit lake, continuous across square edges, at a density data value so most towns will have none within their limits; the fine river generator (ADR-0010) refines these control points later.
