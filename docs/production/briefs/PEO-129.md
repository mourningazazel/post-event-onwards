# PEO-129 · Content: apply modifiers and bake the variant table at load

## Goal

At load, core applies modifier ops (set, add, mul, append, remove; integer rounding per derive.rnd), add and remove tags, composes display names (derive.display_name) and interns each (archetype, modifier set, brand) variant into a baked table, so generation never deep-merges at runtime (item-system review 2026-09-29); golden-checked against derive.apply_modifier and display_name, with a test that generation reads only the table.
