# PEO-130 · Content: generic parents for the remaining item families (D-046)

## Goal

D-054 (3) and (4): every item sits under an abstract category root (item.tool, item.clothing, item.furniture, ...) beneath one item root, every family has a generic parent, and shared data lives on the parent: a child sets only what it changes. The add-nothing rule of PEO-116 is retired, so the seven PEO-116 generics take their families' shared data and the families it left out (lantern, battery, handgun, rifle, trousers, jacket, chair, door and the rest) get parents too. Each family's move is proved by golden.py --unchanged-from (resolved items identical apart from parent and tag order), and cat.* tags become derivable from the roots.
