# PEO-146 · The one map's terrain by world cell: chunk.hpp, map_terrain.hpp, seam-free placeholder walls (PEO-118)

## Goal

Any rectangle of the one map can be generated alone and joins its neighbours exactly: world cells and chunks are 64-bit coordinates in core, and a placeholder tile generator decides each cell's wall from (seed, world cell) only, ready for World to read (PEO-147).

## Context

- docs/adr/0007-endless-staged-world.md (world coordinates are 64-bit; each level a pure function of seed and coordinates); docs/design/world-generation.md 'Principle 1' and the L4 Tile row (32x32 chunks); docs/GAMEPLAN.md §3.2 (chunk = 32x32)
- src/core/src/stage.cpp generate_stage: today's walls are rng.chance(0.10) per cell from one stream, plus border walls; openness outdoors on open cells, indoors on walls. Keep the density and the openness rule; drop the border and the stream
- src/core/include/peo/core/geography.hpp terrain_at / generate_geography: the pattern to copy, a per-cell source of truth and a rect fill equal to it cell for cell (D-041)
- src/core/include/peo/core/rng.hpp hash_u64(a, b, c); types.hpp Vec2i, Seed; grid.hpp Grid<T>

## Units

- core: new header peo/core/chunk.hpp, one concept (where a cell is on the one map): `kChunkSide = 32`; `struct WorldCell { std::int64_t x, y; }` and `struct ChunkCoord { std::int64_t x, y; }` with defaulted <=>, and WorldCell + Vec2i; `chunk_of(WorldCell)` by floor division (cell -1 is in chunk -1, -32 in -1, -33 in -2), `chunk_origin(ChunkCoord)`, `chunk_seed(Seed, ChunkCoord)` from hash_u64 with a named salt. constexpr and noexcept where possible
- core: new header peo/core/map_terrain.hpp with src/core/src/map_terrain.cpp. `struct TerrainParams { std::uint32_t wall_chance = 429496730; }`, a fraction of 2^32 (the old 0.10), integers only. `wall_at(Seed, const TerrainParams&, WorldCell)` is the source of truth: the high 32 bits of hash_u64(seed ^ kTerrainSalt, u64(x), u64(y)) below wall_chance. `fill_terrain(Seed, const TerrainParams&, WorldCell origin, Grid<bool>& blocked, Grid<std::uint8_t>& openness, int x0, int y0, int x1, int y1)` writes the clipped rect [x0, x1) x [y0, y1), grid cell (x, y) being world cell origin + (x, y): blocked is wall_at, openness kOpennessIndoors on walls and kOpennessOutdoors on open cells; an overload without the rect fills the whole grid (both grids one size). Allocates nothing; no border, entry or exit
- test: tests/core/test_chunk.cpp, TEST_SUITE("chunk"), the cases under Tests, each well under 50 ms under the sanitizers (unit tier)
- docs: architecture.md's 'Current code' tree and docs/domains/world.md's table gain chunk.hpp and map_terrain.hpp, one line each

## Acceptance

- `python3 tools/verify.py` passes and suite_budget stays green
- A rect filled in one call equals the same rect filled as four quarters in any order and equals wall_at cell for cell, including rects across negative world cells
- Nothing in World or the app uses the new headers yet

## Tests

- `chunk_of floors toward minus infinity` (0, 31, 32, -1, -32, -33, and plus or minus 2^40)
- `chunk_origin and chunk_of round-trip`
- `chunk_seed is stable and differs between neighbours` (pin two values)
- `a filled rect equals wall_at cell for cell` (70x50 at origin (-40, -20): crosses chunk lines and 0)
- `overlapping fills agree` (two rects sharing a strip, filled in either order: the strip is identical)
- `walls are about a tenth of the map` (256x256: share between 9.5% and 10.5%)
- `the placeholder generator is pinned` (wall count of a 64x64 rect at (1000000, -1000000) and three named cells, so any change is deliberate: ADR-0002 freeze)
- `openness follows the walls`
