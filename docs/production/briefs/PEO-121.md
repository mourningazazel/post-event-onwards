# PEO-121 · What can be made out at range: labels within 20 ft (D-049)

## Goal

Within 20 ft (6 tiles) the player reads signs and sees an item's generic label ("hammer") or a container's kind only; the full description and contents need examining. Labels come from content data (D-046 generic parents, D-030 purposes); Ryan writes all player-facing text (D-042).
