# PEO-093 · verify refuses non-MIT-compatible licenses (ADR-0015)

## Goal

tools/verify.py fails when a dependency the build uses is not recorded in docs/LICENSING.md, or is recorded with an SPDX id outside ADR-0015's MIT-compatible list.

## Context

- docs/domains/process.md
- docs/adr/0015-mit-compatible-dependencies-and-original-assets.md
- docs/LICENSING.md ("Allowed dependency licenses" and "Candidate dependencies")
- tools/validate_docs.py (how docs checks run inside verify.py's docs stage)
- cmake/FindOrFetchSDL3.cmake, tests/CMakeLists.txt, the vendored doctest header (what the build pulls in today)

## Units

- tools: in validate_docs.py, parse LICENSING.md's allowed-license list and the dependency table (Library, License (SPDX)); an entry passes when every SPDX id in its cell (dual licenses: any one allowed id suffices, as zstd and PCG are used under one) is on the allowed list; print one error line per failing row
- tools: list the dependencies the build actually uses (names from FetchContent_Declare / find_package of third-party libraries in CMake files, plus vendored headers under the repo) and fail when one has no row in LICENSING.md; system packages that are not redistributed (Threads, Python3, Vulkan loader) are skipped by a short named allowlist in the script
- test: tests/tools or a self-check mode (`validate_docs.py --self-test`) that feeds a GPL row and an unlisted FetchContent name and expects both to fail, and the real repo to pass
- docs: LICENSING.md gains one line saying verify enforces the table

## Acceptance

- `python3 tools/verify.py --skip-build` passes on main as it is
- adding a row `| foo | test | GPL-3.0-only |` to LICENSING.md makes the docs stage fail with a message naming foo and its license
- adding `FetchContent_Declare(bar ...)` to a CMake file without a LICENSING.md row makes it fail naming bar
- the check adds under 100 ms to the docs stage

## Tests

- the self-test from unit 3, run by the docs stage or CI's docs job

## Manual

- none: tooling only, no game change

## Out of scope

- asset licensing (all assets are original, ADR-0015); THIRD_PARTY_NOTICES generation (later release work); fetching licenses from the network
