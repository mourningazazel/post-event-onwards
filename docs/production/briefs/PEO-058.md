# PEO-058 · The Dead move in staggered slots over a 9 s cycle (D-031)

## Goal

Per D-031. The Dead stop moving in unison. Every 9 game seconds the world polls which of the Dead can move and gives each mover one or more slots (seconds) in the cycle from a hash. At its slot a unit re-reads its best neighbour and decides; the move lands one second later, so the tile it leaves is still occupied when the next second's units decide. A calm Dead never enters a tile holding another Dead, or one reserved by a pending move, and does not pick another direction: it stays put (Ryan: calm Dead do not climb over each other; only alerted Dead push past, later). A crowd therefore files through gaps and jams a one-wide corridor. Speed becomes slots per cycle, replacing PEO-042 (held).

## Units

- core: rng.hpp gains `std::uint64_t hash_u64(std::uint64_t a, std::uint64_t b, std::uint64_t c) noexcept` (splitmix64 finaliser, same constants as reseed) and `float hash_unit(...)` in [0, 1), exactly as PEO-042's first unit specifies, with its doctests in tests/core/test_rng.cpp.
- core: dead.hpp: `decide_move(const Dead&, const ScentField&, const Grid<bool>& blocked, const Grid<std::uint8_t>& occupied, const Grid<bool>& reserved)` returns the strongest neighbour (as today) only if that tile has no Dead and is not reserved; otherwise nullopt. It never falls back to a weaker neighbour. Dead drops cooldown_s and keeps step_seconds. Doctest in tests/core/test_dead.cpp: with the strongest neighbour occupied, the unit gets nullopt even when a weaker free neighbour exists; with it reserved, the same; free, it gets that tile.
- core: WorldParams gains `Seconds dead_cycle = kDeadCycleSeconds` (9). World keeps an occupancy count grid, a reserved grid, per-cycle slot buckets and a pending-move list, all reused buffers (no allocation after warm-up). Slots: at each second t with t % dead_cycle == 0 (and at load_stage), for every unit with a strongest neighbour, k = floor(dead_cycle / step_seconds) plus one more if hash_unit(seed, cycle, index) < the fraction, capped at dead_cycle; its k slots are evenly spaced from offset hash_u64(seed, cycle, index) % dead_cycle. Units with no stronger neighbour at the poll get no slot this cycle.
- core: the per-second order inside advance(), for each second t: (1) units in slot t decide with decide_move; a decided move reserves its target and is pending; (2) moves decided at t-1 land: occupancy of the old tile drops, the new one rises, the reservation clears; (3) if t is an update boundary, run the scent update (step_linear, logged deposits, clamp_floor) as now. Because step (1) runs before step (2), a unit deciding at t still sees a neighbour that decided at t-1 on its old tile. The Dead no longer move inside run_update.
- core: spawn places at most one of the Dead per open tile (redraw on an occupied tile), so occupancy starts valid. This changes some draws: re-pin 'the pre-clock world is pinned' deliberately, in its own commit, with the reason in the message.
- core: speculation. Between updates the Dead read only the scent from the last update, never the player's position or deposits, so their seconds are exact to run live. speculate() computes only the next update's step_linear (the expensive sweep); commit patches the logged deposits and clamps as now, and runs the Dead's seconds live exactly as step() does. Delete kRepatchRadius, near() and the re-decide box; commit(speculate()) must stay bit-identical to step().
- test: tests/core/test_world.cpp: 'calm Dead never share a tile' (300 one-second waits on the small stage and on a stage with a one-wide corridor if the generator can give one, else the small stage only: occupancy of every tile is 0 or 1 after every second); 'a vacated tile waits a second' (record landings per second with one-second waits: whenever a unit lands on a tile another unit left, the leave happened at least 2 seconds earlier); 'slots differ each cycle' (for one unit over 100 cycles its first slot takes every value 0-8 and is not constant; same seed gives the same sequence); 'speed is slots per cycle' (step_seconds 3 gives 3 slots every cycle, 6 gives a mean of 1.5 within 0.05 over 1,000 cycles, 18 a mean of 0.5); extend the golden test with the mixed 1/3/6/12 s script.
- docs: docs/architecture.md, the Dead's update paragraph: the 9 s poll, hashed slots, decide then land one second later, calm Dead never share or sidestep, and that the Dead run live between updates because they read only the last update's scent (D-031).

## Acceptance

- no tile ever holds two of the Dead
- a unit never lands on a tile another unit left less than 2 seconds before
- a unit whose best tile is taken stays put rather than moving elsewhere
- which units move in which second changes from cycle to cycle, deterministically from the seed
- commit(speculate()) is bit-identical to step() for mixed 1/3/6/12 s actions
- at 200x120 with 5000 Dead, commit plus the live Dead seconds of one 6 s walking step stays under 1 ms on headless-release (D-021); report the number and speculate's time
- the suite stays under 1 s
