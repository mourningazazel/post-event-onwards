# PEO-151 · Stage names retired: window and map in core, tests, app flags and docs (PEO-118)

## Goal

Nothing in code or docs suggests the world is staged: Stage, stage(), stage_width / stage_height, kMinStageSide, OffStage, the app's --stage flag and the docs' stage wording become window and map names, and ADR-0007, architecture.md, the world domain page and the wiki describe the one continuous map.
