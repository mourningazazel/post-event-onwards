# PEO-090 · Clock in substeps: 12 per walk, walk is 3 s (ADR-0016)

## Goal

The clock counts substeps (ADR-0016): a walking step and a wait are 12 substeps and read as 3 game seconds (a substep is 250 ms), a running step is 6. Everything that exists today runs on even substeps only, so every seed and action list gives the same world as before, turn for turn, and the pinned hashes do not move. Odd substeps pass, unused. Real-time durations keep their hours, so a game hour is 1200 updates (D-039 A); the scent age bound drops to about 12 game years.

## Units

- core: types.hpp replaces the clock type `Seconds` with `Substeps` (std::uint32_t) and adds kSubstepMs = 250, kSubstepsPerSecond = 4, kSlotSubsteps = 2, kSubstepsPerWalk = 12, and constexpr `to_substeps(seconds)` / `to_ms(substeps)` for durations authored in real time (rounding up, so a non-zero duration is never 0); kUpdatePeriodSeconds becomes kUpdatePeriodSubsteps = 12. Keep a `Seconds` alias only as the authored-duration input of to_substeps, so the compiler finds every clock use
- core: action.hpp: kStepSubsteps = 12, kWaitSubsteps = 12, kRunStepSubsteps = 6; Action::substeps. World treats 0 as one slot (kSlotSubsteps), matching today's 0-as-1 s. Odd durations are legal (the between layer, opt-in; no game input makes one)
- core: dead.hpp/world.hpp: kDeadCycleSubsteps = 18, WorldParams update_period and dead_cycle in substeps, Dead::step_substeps (spawn draw x update_period as now). The constructor rounds update_period, dead_cycle and each spawned step up to a multiple of kSlotSubsteps. plan_slots, slot_second and draw_word take slot indices as above (rename their parameters; keep their bodies)
- core: world.cpp: advance() steps one substep at a time; occupancy logs substeps; on an even substep it runs dead_second / replay_second for slot t / 2 (a decided move lands on the next even substep, D-031's 'one second later'); the update fires when seconds_ % update_period == 0. An odd substep costs the counter and the occupancy add only. speculate_dead records slots up to the boundary and commit replays them; Speculation::from/to stay in substeps, decided_begin indexed by slot. logged_strength uses substeps (age_cost x (12 - held) / 12 equals today's x (6 - h) / 6 for even held). World::seconds() becomes substeps(); add game_ms() for display
- core: scent_wave.hpp: the life bound reads in milliseconds: kMaxWaveUpdates x kUpdatePeriodSubsteps x kSubstepMs >= one year in ms; its comment says about 12 game years at one update per 3 s
- app: main.cpp uses the renamed constants; nothing changes on screen (the HUD shows turns, not time)
- test: rename across tests/core and tests/gpu (constants, durations doubled: today's 1/3/6/12 s are 2/6/12/24 substeps); the three pinned hashes and every other expected value stay as they are, with no re-pin
- test: new cases in test_world.cpp: (a) a walk is 12 substeps and game_ms() reads 3000 after one, a run 6, a wait 12; (b) two waits of k and 12 - k substeps, for every k in 1..11, give a World::equivalent world to k = 6 (same turn count), so stopping on an odd substep changes nothing; (c) the commit(speculate()) golden draws durations from {1, 2, 3, 6, 12, 24} so recorded windows start and end on odd substeps; (d) to_substeps / to_ms: 3 s is 12, an hour is 14400, 1 ms rounds up to 1
- siege: per_hour = kSubstepsPerHour / update_period (1200), so the checkpoints keep their game hours; rewrite the baseline with ADR-0016 as the reason in the commit
- docs: architecture.md's clock section and slots paragraph in substeps; bottlenecks.md multiplier 'one slept game hour is 1200 updates'; time.md lists PEO-090 as active, not deferred
