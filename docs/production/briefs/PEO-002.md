# PEO-002 · Introduce World as the turn-based step owner

## Goal

The game is turn-based: World::step(Action) is the only way time moves, the frontend holds no simulation state, and the world waits for the player.

## Units

- core: add src/core/include/peo/core/action.hpp: enum class ActionKind { Step, Wait }; struct Action { ActionKind kind; Vec2i dir; static Action step(Vec2i); static Action wait(); }.
- core: add src/core/include/peo/core/world.hpp: struct WorldParams { int initial_dead = 40; float player_scent = 1.0F; ScentParams scent; }; class World { public: World(Seed, WorldParams = {}); void load_stage(uint32_t); void step(Action); const Stage& stage() const; const ScentField& scent() const; const std::vector<Dead>& horde() const; Vec2i player() const; Tick turn() const; uint32_t stage_index() const; }. No clock, no thread, no SDL.
- core: implement src/core/src/world.cpp by moving load_stage/try_move/simulate out of main.cpp. step(): apply action (a Step into a wall becomes a Wait, still consumes the turn), deposit scent at player cell, scent.step(&blocked), step_horde, ++turn; reaching the exit loads the next stage at the end of the turn. Add both files to src/core/CMakeLists.txt.
- test: tests/core/test_world.cpp — 'same seed same world after 100 turns' (two Worlds fed the same actions: equal player, horde, scent.total()), 'step into wall consumes the turn but does not move', 'wait advances the turn and the dead approach', 'reaching exit advances stage_index'. Register in tests/CMakeLists.txt; suite stays under 500 ms.
- app: main.cpp keeps SDL setup, key mapping, draw(). App holds a World and a 'dirty' flag; a key press calls world.step(Action) exactly once; nothing advances on a timer. Remove kTickMs, last_tick_ms and the pause toggle (a turn-based game has no pause). Keep Shift+S scent view and N next stage.
- docs: in docs/architecture.md 'Planned seams', mark World as built and note the file names.

## Acceptance

- src/app/main.cpp contains no ScentField, Rng, Dead or Stage manipulation; only World calls, input mapping and drawing
- the world does not change while the player is idle for 10 seconds
- one key press moves the player one cell and the Dead one step at most
- the four new world tests pass; whole suite under 500 ms

## Manual

- Run ./build/dev/bin/peo 7. Do nothing for 10 s: nothing on screen may change.
- Press right 20 times: @ moves one cell per press; the d glyphs close in one cell per press.
- Hold a movement key: movement must feel immediate with no queued lag after release (report the OS key-repeat feel).
- Press . or space (wait): the Dead advance one step while @ stays.
- Walk into > : stage counter increments and the map changes.
