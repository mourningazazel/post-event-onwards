# PEO-135 · Content format: .peo parser in core and tools, one-time TOML converter (D-057)

## Goal

D-057: content/ is written in the .peo format of docs/design/content-format.md and read by one parser spec shared by core (replacing toml++) and the Python tools (replacing tomllib): records by full path, comma-terminated fields, verbatim and formatted strings, units with metric-only lengths, dims blocks, text records and generators, the shared root tree. A one-time converter rewrites today's content (word scales become integers, references become full paths), proved by golden output before and after. Split into Architect-briefed items when planning; the root tree waits on the owner's approval.
