# PEO-132 · Content: one reference path for every record, following references (D-054)

## Goal

D-054 (1) and (2): any record is addressable by its full path from its root (item.tool.hammer.claw_hammer, derived from the parent chain) as well as its flat ID, and one path can step through a reference into the record it names (...composition.handle.material.hardness), in core's Content and in the Python tools alike, with no allocation per lookup. The exact syntax comes from PEO-134.
