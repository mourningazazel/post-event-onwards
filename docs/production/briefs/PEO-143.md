# PEO-143 · Content: switch content/ to .peo, tools to the new field names, drop toml++ (D-057)

## Goal

content/ is .peo only: to_peo.py's output is committed and every content TOML file deleted. The frontend and peo_content_dump read *.peo; common.load is peo_load; lint, derive, generate, golden and test.py, and the test fixtures in tests/content/{chains,expectations,rolls}, use the new full paths and field names; load_content's TOML adapter and toml++ are removed, and tomllib reads only test fixtures. The game plays exactly as before.

- tools/content/to_peo.py, peo_load.py and golden.py --peo (PEO-136); content.cpp's TOML adapter and content_golden_peo (PEO-142)

## Units

- content: run to_peo.py over content/ into content/, commit the .peo files, and delete every content/**/*.toml by explicit path. One commit; golden.py --peo run just before it is the proof
- tool: common.load becomes peo_load (Db, origin and errors as before; RECORD_TYPES stays the type list). lint, derive, generate and test.py move to the new field names and units (dims block, mass in g, percents, ranges, compartment blocks), resolve Refs through a path index on Db (a reference is valid when its path names a record of the expected type), and read tags as def.tag paths. tests/content/{chains,expectations,rolls} stay TOML test specs, updated to the new IDs and field paths. golden.py drops its TOML half, back_to_toml and --peo; to_peo.py is deleted (git keeps it)
- core/app: load_content reads .peo only (a .toml source is an error naming the file), the TOML adapter goes, toml++ leaves third_party and CMake; read_content_files and peo_content_dump read *.peo by default; content_golden runs on content/ and content_golden_peo goes. The inline sources in test_content.cpp, test_content_migration.cpp and test_look_label.cpp become .peo
- docs: content/README.md rewritten as the .peo field reference (the converted schema, examples in .peo); docs/architecture.md, docs/wiki/build-and-test.md and api-reference.md say content is .peo; the toml++ decision entry gets its superseded line
