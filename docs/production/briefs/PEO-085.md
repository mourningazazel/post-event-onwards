# PEO-085 · Pull kernel portability and Speculation ownership: AVX2 on MSVC, no target_clones on Darwin, foreign Speculation cold-copies

## Goal

The PEO-078 pull runs its AVX2 path on Windows (MSVC) via a run-time dispatch, compiles on any x86 Apple toolchain, and a Speculation last synced from another World (same token, same size) falls back to a full copy instead of a partial sync, with a test that reuses one Speculation across two Worlds.
