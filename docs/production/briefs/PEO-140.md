# PEO-140 · Details from the seed: detail tables in core, rolled per address; a sign's text (D-023, PEO-121)

## Goal

Split from PEO-050. Content exposes each item's detail tables and their entries; a thing's details are picked from its address with a counter-based hash (table, entry index), the same for an implied unit read through its seed and for the Thing it instantiates as; a readable sign's text is its rolled detail entry, which PEO-121 shows within 20 ft. Entries are named by table and index so PEO-137's move of prose into text records changes only the loader.
