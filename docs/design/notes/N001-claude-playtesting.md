# N001 — Claude must be able to play and test the game during development

- Date: 2026-09-27
- Source: owner, in session

> I want you, as you come up with this, make sure you have a way to play the game during
> development and test out functions yourself. I want you to, as you design this, and since the
> game can be played with keyboard input, create test cases and test playthrough you can do. you
> can control the amount of units, the type of scenario etc, and go through full gameplay cycles.
> I want you to create these as tests so you can actually physically test the game. This is more
> than just technical testing, as i want you to examine the game for gameplay elements that break
> other functions or introduce other bugs that might not be purely technical
