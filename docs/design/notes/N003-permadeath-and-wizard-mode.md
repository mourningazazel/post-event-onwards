# N003 — Hard permadeath, and a wizard mode

- Date: 2026-09-27
- Source: owner, in session

> And yes, please have a wizard mode. And there is permadeath, so i appreciate things just ending a
> run out of stupid decisions or bad luck. If you are 50 hours in on a player and you die because
> you fell in a ditch and can't get up? sorry, thats just how it is.

## Decisions this settles

- **Walkthrough G04 D4.4:** option **A, permadeath.** Death ends the run.
- **Playtest harness D-PT1:** wizard mode **ships**, clearly marked.
- **Walkthrough G13 (general principle):** realism over protection. Getting permanently stuck, or
  dying through bad luck or bad decisions, is **intended**. The gameplay rule checker must not
  treat it as a bug.

## Follow-up question

- After a permadeath, does the next run start in a **new world**, or with a new character in the
  **same persistent world**, where your old body might be found? Recorded in G04 D4.4.
