# N002 — Track the intended uses of gameplay functions, and test that they stay possible

- Date: 2026-09-27
- Source: owner, in session

> Make sure that when you create the playtests, you are keeping track of intended uses of gameplay
> functions ("what should this be used for?") and creating tests to make sure that those functions
> are able to be done. Keep these tests going forward, so you can identify when a new changes
> breaks a previous mechanic. If you are unsure of what the purpose of something is, just ask and
> you can better contextualize your own testing.
