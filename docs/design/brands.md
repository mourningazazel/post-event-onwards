# Brand universe: starter set (fictional)

Origin: owner note [N010](notes/N010-name-attachment-joints-descriptions-brands.md). Mechanics
are described in [`content-model.md`](content-model.md) §9.

**Rules:**

- Every name is invented to sound believable **without resembling real brands**.
- Each name passes a **conflict check** (web and trademark search) before any content ships.
- Status column: ⏳ = not yet checked.
- Tiers: **B** budget, **S** standard, **P** premium. The tier shifts relevant item properties
  (e.g. tape Hold, battery charge).

## How the universe grows

When Claude authors a brandable archetype, it adds a handful of brand options drawn from fitting
categories. New parent companies or brands are added here when a category has no fitting brand.
Regional weighting (which brands are common where) is part of the region generator's data.
